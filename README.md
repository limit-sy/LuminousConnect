## 1. 作品概要
本作は、光を失いゆく「ルミナスボール」を、輝きが消える前にゴールへと導く3Dゴルフアクションゲームです。  
単なるアクションに留まらず、UIによる情報の可視化や、プレイヤーを導く案内人との会話システムなど、ユーザーエクスペリエンス（UX）を意識した作品作りを目指しました。

* **ゲームプレイページ**: <a href="https://limit-sy.github.io/luminousconnect_gameplay/" target="_blank">[こちらからプレイできます]</a>
* **リポジトリ**: <a href="https://github.com/limit-sy/LuminousConnect" target="_blank">[GitHub - LuminousConnect]</a>
* **制作期間**: 2026年3月31日 ～ 2026年4月20日

## 2. 開発の背景と目的
前作の3Dアクション制作を経て、今作では「プレイヤーを飽きさせない誘導」と「独自のゲームシステムの構築」をテーマに設定しました。

* **演出の追求**: 既存のアセットに頼らず、一から独自の会話システムを設計。プレイヤーが能動的に物語や操作説明を読み進めたくなる演出を研究しました。
* **UXの最適化**: 3D空間での視点操作のしづらさを解消するため、CinemachineとInput Systemを連携させ、キーボード・ゲームパッド操作に特化した快適なカメラワークを実装しています。

    ## 4. 技術的な実装のポイント
### ① 独自会話システムの構築とドラマチックなテキスト演出
案内人との会話シーンは、スクリプトからUIレイアウトまでを一から独自に構築しました。単にテキストを表示するのではなく、1画面の文字数を「22文字×2行」に制限し、名作アドベンチャーゲームのような「独特の間」や「タメ」を意識したロジックを実装。ユーザーへのチュートリアルを退屈させないよう、プレイヤーの没入感を高める工夫を凝らしています。

### ② CinemachineとInput Systemの高度な連携
マウス操作を排し、キーボードとゲームパッドに特化した視点操作を構築。エイム（狙い）時にはカメラアングルを最適化し、プレイヤーが意図した方向へ正確に打ち出せるよう制御しています。

### ③ 状況に応じた動的なUI制御
`CanvasGroup` を活用し、会話中とプレイ中でHUDの表示状態を滑らかに切り替えるマネージャーを実装。スクリプトを停止させずに見た目のみを制御することで、状態遷移に伴う不具合を防ぎ、洗練されたプレイ体験を提供しています。

```C#
// UIController.csより抜粋：会話フラグを監視し、アルファ値で表示・非表示を制御
void Update()
{
    if (DialogueManager.IsTalking)
    {
        canvasGroup.alpha = 0f; // 会話中はUIを透明化
        canvasGroup.blocksRaycasts = false;
    }
    else
    {
        canvasGroup.alpha = 1f; // 操作時はUIを再表示
        canvasGroup.blocksRaycasts = true;
    }
}
```

## 5. 作品の遊び方
案内人との会話からゲームがスタートします。  
広大なフィールドでボールを打ち出し、規定打数（PAR）内でのゴールを目指してください。  
ボールを打つたびに輝きが弱まっていくため、効率的なルート選びが重要です。  
![ゲーム画面](readme_img/gameplay1.png)
| アクション | キーボード | ゲームパッド |
| :--- | :--- | :--- |
| **移動** | 方向キー | 左スティック |
| **カメラ移動** | `W` / `A` / `S` / `D` | 右スティック |
| **エイムモード** | `X` | `R1` ボタン |
| **ショット** | `C` (長押しでパワー) | `□` ボタン |
| **会話送り** | `Enter` / `C` | `East` ボタン |

## 6. 今後の課題
前作では書籍の構成に頼っていた部分がありましたが、今作では「なぜその設計にするのか」を自問自答しながら、自分なりのクラス設計（UIの管理、カメラの制御など）を盛り込むことができました。  
一方で、ステージが広大になるにつれて、オブジェクトの管理やパフォーマンスの最適化について、より深く学ぶ必要があると感じています。

### 今回のゲームをもっと面白くする課題
* **ゴルフステージのバリエーションの追加**: 動く床や風、ワープなどの物理演算を活かしたステージギミックの追加。
* **続きのストーリー**: 先が気になるストーリー、演出の考案、実装
* **ビジュアルの強化**: ボールの「輝き」の変化に合わせたライティングやエフェクトの動的な演出、アセットの使用など。
* **オンライン要素**: 最小打数（ハイスコア）を競うためのオンラインランキング機能の実装。

## 7. 所感
今作で最も力を入れたのは、ゼロからの会話システムの構築と、そこでの「言葉選び」です。  
3Dアクションとしての手触りを追求するのはもちろん、案内人というキャラクターを通じてプレイヤーを導くための「読みやすさ」や「物語の引き」を自力で実装できたことは、大きな自信に繋がりました。  
技術的な実装力と、プレイヤーを楽しませる演出力の両面を意識できた「LuminousConnect」の開発経験を糧に、次作ではさらに洗練されたクラス設計と没入感のあるゲーム体験の両立を目指します。
